# MaintiDoc

Dépôt de documentation pour la maintenance RAM.

## Structure

- `docs/diagrammes/` : sources des diagrammes (draw.io, Mermaid, etc.)
- `corpus/documents/` : articles et documents de référence
- `corpus/images/` : captures d'écran / images de dépannage
- `corpus/inventaire.csv` : inventaire des ressources du corpus
- `corpus/prompts_corpus.md` : prompts associés au corpus

## GitHub

Remplacez l'URL ci-dessous par le dépôt GitHub public ou partagé avec l'enseignante :

https://github.com/<votre_compte>/<votre_repo>

## Notes

- Les fichiers sensibles, clés et variables d'environnement sont ignorés par `.gitignore`.
- Si le corpus dépasse les limites de Classroom, ajoutez un deuxième lien de partage dans le fichier `L1_MaintiDoc_<NomEquipe>_LienGitHub.txt` situé à la racine du ZIP.
